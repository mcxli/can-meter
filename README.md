# CANメーター

スバル BRZ（ZC6、2014年式、MT）のCANデータとGPS情報を取得し、車両情報をリアルタイムに表示する自作メーターです。走行後の分析用に、取得データをCSVで保存します。

## 現状

設計段階です。環境構築・実装・実機検証は未実施で、ファームウェア等のコードはまだありません。

## システム構成

```text
車両のOBD2端子
    │ CAN（受信専用）
    ▼
メイン機：Waveshare ESP32-S3 4.3B
    ├── LVGLによるメーター表示
    └── Micro SDカードへのログ保存
    ▲
    │ Wi-Fi
サブ機：M5Stack ATOM S3 Lite
    ▲
    │ ケーブル接続
M5Stack GPSユニット
```

## 安全方針

- CAN通信はListen-onlyによる受信専用とし、データフレーム、診断要求、ACK、エラーフレームを送信しません。
- 純正ECUは変更・書き換えを行いません。

# CANメーター 開発手順

## 位置付け

[要件定義書](docs/開発手順/要件定義.md)を実装するための作業計画。これらの文書の作成時点では、環境構築・実装・実機検証は未実施。
記載したファイル構成・データ項目・測定方法は実装案とし、実装で確定した内容を各文書へ追記する。要件の採用機器を再選定する作業は行わない。

## 進める順番

| 段階 | 詳細手順 | 主な成果 |
| --- | --- | --- |
| 1 | [開発環境](docs/開発手順/01_開発環境.md) | Macから両機へ書き込める環境 |
| 2 | [メイン機の基本動作](docs/開発手順/02_メイン機の基本動作.md) | 画面・タッチ・SDの動作確認 |
| 3 | [メーター画面](docs/開発手順/03_メーター画面.md) | 仮データによる4画面 |
| 4 | [GPS・通信](docs/開発手順/04_GPSと通信.md) | GPS受信とWi-Fi転送 |
| 5 | [ログ保存](docs/開発手順/05_ログ保存.md) | CSV保存・時刻対応・記録停止 |
| 6 | [実車CAN受信](docs/開発手順/06_実車CAN受信.md) | Listen-onlyによる生ログ |
| 7 | [車両情報の復号](docs/開発手順/07_車両情報の復号.md) | 実データでのメーター表示 |
| 8 | [統合確認](docs/開発手順/08_統合確認.md) | 性能・継続動作・異常時の評価 |
| 補足 | [自動終了と電源断対策](docs/開発手順/09_自動終了と電源断対策.md) | 自動保存終了・電源保持・給電停止 |

自動終了のソフトウェア処理は段階5と併せて実装し、電源保持回路を含む確認は段階8までに行う。

段階1〜5は車両に接続せず進める。段階6以降もCAN通信は受信専用とする。
ハードウェアが未接続の場合、環境構築・コード作成・ビルドは進められるが、実機の完了条件は未確認として残す。

## 推奨する成果物構成

```text
firmware/
  main/          メイン機のESP-IDFプロジェクト
  gps/           サブ機のESP-IDFプロジェクト
  shared/        共通の通信形式・データ定義
docs/
  開発手順/      本文書群
  実装仕様/      接続・画面・通信・CAN解析・ログ形式
  検証結果/      実測値・条件・判定・問題点
tools/           CSV確認・CANログ再生等の補助ツール
```

上記は構成案であり、現時点ではファームウェア等は作成していない。

## 各段階で残す記録

- 実施日、対象機器、ファームウェアの版。
- ESP-IDF・依存ライブラリの版とビルド設定。
- 実施条件、期待結果、実測結果、合否。
- 未確認事項と次に行う作業。

不合格を解消するために要件を変更する場合は、理由・実測値・変更内容を要件定義書に反映する。

# CAN情報の調査（CAN-03）

要件 CAN-03「ZC6向けに公開されたCAN情報を調査し、解析仕様の参考とする」の調査結果。調査日は2026-11-12。

**ここに書いた内容は、すべて「候補」である。** 出典はコミュニティの記録・個人のプロジェクト・メーカー外の資料で、実車（2014年式BRZ ZC6・MT・純正ECU）の生ログで確認するまで、確定情報として扱わない（段階6・7）。要件 CAN-07 のとおり、IDの存在だけで、値の意味が確定したと扱わない。

## 調査の範囲と方法

- 対象は、初代（ZC6／ZN6、2012〜2021年式。出典ごとに年式の表記が異なる）。2代目（2022年式以降のBRZ／GR86）のIDは、初代と別で、**混在させない**。
- 方法は、Web検索と、各ページの本文の取得。取得できたものと、できなかったものを区別して記す。
- 診断要求（OBD-IIのPID要求）の送信が必要な情報は、対象外（受信専用の方針。CAN-04）。

## 温度の単位（水温・油温）

出典B（ft86 gen1.md）の原文を確認した（2026-11-12）。水温は `D - 40`、油温は `C - 40` と書かれているだけで、**単位（℃か℉か）の記載はない**。

- 「−40」のオフセットは、「摂氏の値に40を足して、0以上の整数で送る」形として、多くの車で使われている。このため、摂氏の可能性が高いと**考えられる**が、出典に記載がないため、確定しない。
- 北米向けの車は、メーターの表示が華氏になることがある。CANの生の値が、摂氏のままか、表示の単位に合わせて変わるかは、この調査では分からない。出典Bの記録は、北米・欧州の車が元になっている可能性がある（未確認）。
- 出典A（Racelogic）は、水温・油温の単位を「°C」としている。ただし、これは同社のソフトが、換算後に出す単位であり、CANの生の値の単位ではない。
- **確認方法**：実車で、エンジンが冷えている状態（始動前・停車後しばらく置いた状態）の生の値を見る。気温15℃なら、摂氏なら約55、華氏なら約99になる。暖機後は、純正メーターの水温表示と、傾向（上がり方・安定する値）を比べる。診断要求の送信が必要な機器は、本システムでは使わないため、比較は、純正メーターの表示と外気温で行う。
- 日本仕様のZC6は、メーターも摂氏が普通だが、実車で確認するまで、確定扱いにしない。

## 手順書・設計への影響

1. **通信速度**：500kbps、11ビットIDを、段階6の初期値にする（[06_実車CAN受信](../開発手順/06_実車CAN受信.md) の手順4）。実測の受信結果で確認する。確認できない場合は、確定情報として扱わない。
2. **ギアのN（ニュートラル）**：CANからの直接値（0x141のバイト6）が使える可能性がある。ただし、値の意味が不明確なので、実車ログで確かめるまでは、**推定のみで、N・Rを確定しない**という手順書の方針（07）を維持する。
3. **取得できる項目**：回転数・水温・油温・アクセル・ブレーキ・舵角・車速・ギアは、公開情報に候補がある。**受信だけで取得できる**見込みだが、実車で確認する（SIG-01〜08）。
4. **範囲の目安**：水温・油温の取りうる範囲は、調査では得られなかった。画面の範囲（仮）は、実車の値で確定する（段階7）。

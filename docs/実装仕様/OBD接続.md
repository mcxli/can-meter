# OBD-II（CERRXIANケーブル）ピン配置・配線色まとめ

段階6（[実車CAN受信](../開発手順/06_実車CAN受信.md)）で、OBD-IIからメイン機へ接続するための接続表。

## 位置付け

- 使用するケーブルは、CERRXIAN製のOBD-II分岐ケーブル（16本の線が出ているもの）とする。
- 配線色は、このケーブルの色である。製品やロットによって色が変わることがある。**テスターでの導通確認は、まだ行っていない**。
- 接続前に、コネクタのピン番号と線の色の対応をテスターで確かめ、結果を `docs/検証結果/` に記録する。この確認が済むまで、色だけを見て接続しない。
- OBD-IIの6番がCAN-H、14番がCAN-Lであることは、複数の公開情報で一致している（[CAN情報の調査](CAN情報の調査.md)）。実車での受信は未確認。
- CAN通信は受信専用（Listen-only）とする（CAN-04）。

## 1. メイン機との接続に使用する3本（必須）

| OBDピン番号 | ケーブルの色 | 信号名 | メイン機（ESP32）の接続先 |
| :--- | :--- | :--- | :--- |
| **5** | イエロー (黄) | シグナルアース (Signal Ground) | **GND** |
| **6** | グリーン (緑) | CAN-High (CAN-H) | **H** |
| **14** | ブラウン/ホワイト (茶/白) | CAN-Low (CAN-L) | **L** |

メイン機側の「GND」「H」「L」は、メイン機のCAN端子の表記を指す。端子の位置とGPIOの対応は、段階6で回路図・公式サンプル・実機と照合して記録する（未確認）。

## 3. 作業時の注意事項

- **ショート防止**: 16番ピン（緑/白）には常時12Vがかかっている。使用しない他の12本と合わせて、計13本の先端を、1本ずつビニールテープや熱収縮チューブで確実に絶縁する。
- **GNDの重複接続禁止**: 4番（オレンジ）と5番（イエロー）を、メイン機側で1本にまとめない（片方のみ接続する）。
- **給電方法**: メイン機への電源は、16番ピンから直接取らない（破損するため）。USB給電、または12V→5V/3.3Vの降圧回路を経由する。

## 未確認の事項

段階6で確認し、結果を `docs/検証結果/` に記録する。

- ケーブルのピン番号と色の対応（テスターでの導通確認）。
- メイン機のCAN端子の位置・表記と、CANコントローラーのGPIO。
- メイン機の終端抵抗の有無と設定。車両の既存バスにつなぐため、終端を外す必要があるかを、回路図と実機で確認する。
- 車載時の給電方法（降圧回路・電源保護・ACC連動）。自動終了との関係は[自動終了と電源断対策](../開発手順/09_自動終了と電源断対策.md)を参照する。

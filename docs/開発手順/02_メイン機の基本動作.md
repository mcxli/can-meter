# 2. メイン機の画面・タッチ・SD確認

## 目的・対応要件

Waveshare 4.3Bの基本機能を、車両・GPS・CAN解析から独立して確認する。
対応：HW-01・05、UI-02、DEV-04・05。
前提：[段階1](01_開発環境.md)のメイン機書き込みが完了していること。

## 作業手順

1. 4.3B用の公式ESP-IDFサンプルを、対応する依存関係のままビルド・書き込みする。
2. LCD初期化後に文字・図形を表示し、画面の向き・色・表示領域・ちらつきを確認する。
3. タッチ座標を表示し、四隅と中央を操作する。表示位置とタッチ座標が合っているか確認する。
4. LVGLのイベントを使ったボタンを設け、押下回数を画面に表示する。
5. SD初期化処理を確認する。SPIとチップセレクト等の設定は、採用機器用の公式サンプルに合わせる。
6. SDに確認用ファイルを作成し、書き込み・追記・読み出し・クローズを行う。既存の利用者ファイルを上書きしない保存先を使う。
7. ファイルを閉じて電源を切り、SDをMacで読み出して内容を照合する。
8. LCD・タッチ・SDを同時に動かし、初期化順や共有周辺機能の設定に問題がないことを確認する。

## 記録する内容

| 対象 | 記録内容 |
| --- | --- |
| LCD | 解像度、向き、色設定、表示サンプル |
| タッチ | 座標変換、四隅・中央の反応 |
| SD | 容量、ファイルシステム、初期化設定、作成ファイル |
| 依存関係 | ESP-IDF・LVGL・ボード用ライブラリの版 |

SDを認識しない場合は、初期化ログ・カード形式・接続設定を確認する。自動フォーマットは初期化失敗時の既定動作にしない。

## 成果物・完了条件

- [ ] 画面表示・タッチ操作・SD読み書きがそれぞれ成功する。
- [ ] 同時動作でも表示と操作が継続する。
- [ ] Macでファイル内容を確認できる。
- [ ] 初期化処理と動作した設定を再利用可能な形で残した。

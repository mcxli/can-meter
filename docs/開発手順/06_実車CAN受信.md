# 6. Listen-onlyでの実車CAN受信

## 目的・対応要件

2014年式BRZ ZC6・MT・純正ECUから、生CANフレームを受信・保存する。
対応：HW-06、CAN-01・04・05、LOG-04・05、TEST-02。
前提：段階5のログ保存が動作すること。CAN IDの復号は次段階で行う。

## 接続前の実装作業

1. 採用基板の回路図・公式サンプルと実機を照合し、CAN端子とコントローラーのGPIO・切り替え設定を記録する。
2. 対象車両の資料に基づきOBD2側のCAN-H/L・GND等を確認し、メイン機との接続表を作る。
3. 給電元・GND接続・電源保護・既存バスへ接続するときの終端抵抗設定を接続手順に残す。
4. 通信速度・フレーム形式は対象車両の公開資料を起点に設定し、実測した受信結果で確認する。不明な値を確定情報として記載しない。
5. CANドライバーを明示的にListen-onlyへ設定する。通常モードや自己試験モードへ自動的に切り替える処理は入れない。
6. 全受信フレームをログへ送り、表示項目によるIDフィルターをかけない。送信・診断要求の処理を実装しない。

CANコントローラーのListen-only動作を使う。アプリが送信関数を呼ばないだけでは、ACK等も送らないことの確認にはならない。

## 確認手順

1. 車両から離したベンチ環境で初期化設定と起動ログを確認する。
2. 使用可能なCAN試験設備があれば、既知のフレームを受信し、CANコントローラーの送信出力を測定する。相手側は試験機のListen-only受信機からACKが返らない条件でも送信できる構成とする。
3. 実車への接続は接続表に従い、まず停車中に行う。車両の電源状態と給電手順を記録する。
4. 受信件数・ID・DLC・データ・受信時刻・エラー・キューあふれを確認する。
5. 起動、受信開始、記録停止、再起動の各状態で受信専用設定を維持することを確認する。
6. USBとCANの同時利用条件に制約がある場合は、SDログ等で結果を取得する。
7. 記録を正常停止し、Macで生ログを読み出す。車両状態・期間・設定を添える。

## 非送信の評価

| 確認 | 得られる根拠 |
| --- | --- |
| コード・設定の確認 | Listen-only設定、送信経路がないこと |
| コントローラー送信出力等の測定 | 試験条件下でACK・エラーを含む送信動作がないこと |
| 実車ログの確認 | 受信データと車両状態。これだけでは自機の非送信を証明しない |

測定設備がなく設定確認のみの場合は、非送信の実測を未確認として残す。受信できない場合も診断要求の送信で補わない。

## 成果物・完了条件

- [ ] 接続表、通信設定、終端抵抗・給電・USBの条件を記録した。
- [ ] 生CANログをMacで読み出せる。
- [ ] Listen-only設定と非送信について、確認方法・根拠・未確認点を記録した。
- [ ] 受信レート、エラー、キューあふれを記録した。
